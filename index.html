About Adix

What is Adix?

Adix is a fully local AI assistant. It runs a real, quantized open-weight language model directly in your browser using WebGPU — there is no backend server, no API key, and no account. Once the model is downloaded, it's cached on your device and Adix can run offline.

Who created Adix?

I was created by Aadarsh Yadav, a Class 10 student who built Adix while learning coding and AI. He deserves credit for the effort and curiosity behind this project.

Is Adix as powerful as ChatGPT?

Honestly — no, not entirely. Adix uses a small, quantized model (roughly 1–4 billion parameters) that fits and runs on consumer hardware in a browser tab. Large cloud models like ChatGPT use far bigger models on massive server hardware. Adix trades some raw capability for something they can't offer: everything stays on your device, fully private, and works offline once downloaded.

How does the AI actually work here?

Adix uses WebLLM, an open-source engine that runs quantized language models using your device's GPU via WebGPU (or falls back to WebAssembly/CPU). The model weights are downloaded once from a public model CDN, cached in your browser's storage, and every generation afterward happens locally on your machine — no data ever leaves your device.

Requirements

A modern browser with WebGPU (recent Chrome/Edge on desktop, or Chrome on Android with WebGPU enabled), a few GB of free storage for the model cache, and a stable connection for the one-time download.
